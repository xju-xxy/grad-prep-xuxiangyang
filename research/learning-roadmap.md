# 学习路线：知识增强的多 Agent 灾害态势推理与辅助决策

> 制定时间：2026-10-03
> 适用对象：0 基础入门（已会 Python 基础、正在学深度学习）
> 原则：**先会用，再懂原理；先跑通，再创新**。每阶段都要有产出（笔记/代码）。

---

## 0. 这个方向到底在做什么（先建立直觉）

一句话：**灾害发生后，让多个 AI 智能体分工协作，结合专业知识库，分析局势、预测发展、给救援指挥长出主意。**

四个关键词：

| 关键词 | 大白话 |
|--------|--------|
| 多 Agent | 一群分工不同的 AI（情报员、分析员、预测员、参谋、总指挥） |
| 知识增强 | 给 AI 外挂专业资料库（应急预案、知识图谱、实时数据），减少胡说 |
| 灾害态势推理 | 判断"现在啥情况、接下来会怎样" |
| 辅助决策 | 给出行动建议，最终由人拍板 |

## 第一阶段：打地基（第 1～2 周）

目标：能熟练写 Python、会调大模型 API。

- [ ] Python 基础巩固：函数、类、字典、列表推导式、`requests` 库
- [ ] 申请一个国产大模型 API key（DeepSeek 或智谱 GLM，便宜、对学生友好）
- [ ] 跑通第一次 API 调用：发一句话，收到回复，打印出来
- [ ] 理解 token、上下文、system prompt 是什么
- [ ] 学会用 `python-dotenv` 管理 key（不要把 key 写死在代码里！）

**产出**：一个能对话的 Python 小脚本 `engineering/src/llm-basics/01_api_hello.py`

---

## 第二阶段：理解单 Agent（第 3～4 周）

目标：搞懂"一个智能体"是怎么运转的。

- [ ] 理解 Agent 三件套：**规划（Planning）、记忆（Memory）、工具调用（Tool use）**
- [ ] 读懂 ReAct 范式：观察 → 思考 → 行动 的循环（读论文 07）
- [ ] 手写一个最简单的 ReAct Agent：让大模型能调用"计算器"工具
- [ ] 理解 Function Calling（函数调用）的机制

**产出**：论文 07-ReAct 精读笔记；一个能调用 2～3 个工具的小 Agent

---

## 第三阶段：知识增强 RAG（第 5～7 周）

目标：让大模型能"查资料"再回答，这是"知识增强"最主流的做法。

- [ ] 理解 RAG 全流程：切分文档 → 向量化（embedding）→ 存向量库 → 检索 → 塞进 prompt
- [ ] 读 RAG 开山论文（论文 06）
- [ ] 动手：找几份 PDF（比如公开的《国家突发公共事件总体应急预案》），做一个"应急预案问答机器人"
- [ ] 学会一个向量库：Chroma 或 FAISS（本地跑，不用服务器）
- [ ] 了解知识图谱（KG）入门：实体、关系、三元组；知道 Neo4j 是什么

**产出**：论文 06-RAG 精读笔记；一个能回答应急预案问题的 RAG demo

---

## 第四阶段：多 Agent 协作（第 8～10 周）

目标：让多个智能体分工配合。

- [ ] 理解多 Agent 的协作模式：分工、对话、辩论、层级（管理者-执行者）
- [ ] 读 AutoGen 论文（论文 08），装好框架跑通官方第一个例子
- [ ] 把第三阶段的 RAG 问答机器人，改造成"双 Agent"：
      一个查资料（情报员），一个出方案（参谋）
- [ ] 了解其他框架（知道名字和区别即可）：CrewAI、LangGraph、MetaGPT

**产出**：论文 08-AutoGen 精读笔记；双 Agent 版问答 demo

---

## 第五阶段：进入灾害领域（第 11 周起）

目标：读懂领域论文，开始复现。

- [ ] 先读综述（论文 03），建立全局地图：灾害四阶段（减缓/准备/响应/恢复）
- [ ] 精读 WildfireGPT（论文 04）：RAG + 多 Agent + 自然灾害，和你方向最贴
- [ ] 精读 E-KELL（论文 05，IJDRR 期刊一区）：知识图谱 + LLM + 应急决策，中文应急预案数据
- [ ] 选定 1 篇作为复现对象（建议 WildfireGPT 或 E-KELL，二选一）
- [ ] 找数据 → 搭流程 → 跑通 → 写复现报告

**产出**：论文 03/04/05 笔记；复现代码放 `research/reproduction/`；复现报告
