### 建议阅读顺序

1. **03 综述**：先建立领域全局地图（不求全懂，知道大家都在做什么）
2. **07 ReAct**：理解单个 Agent 怎么"思考+行动"（较短，适合入门）
3. **06 RAG**：理解知识增强的核心技术
4. **08 AutoGen**：理解多 Agent 怎么协作
5. **41 多智能体综述**：建立多智能体系统的坐标系（四大维度）
6. **04 WildfireGPT**：方向最贴合的实战系统
7. **05 E-KELL**：知识图谱+应急决策，做复现的重点候选
8. **21 SSTKG**：时空知识图谱（灾害数据的天然形态）
9. **63 Sim911 / 62 LogiDebrief**：灾害应急一线的两个落地系统（一个练、一个查）
10. 其余按需查阅：知识图谱类优先 10/11/13/14/15/16/19/20/22/24/27，多 Agent 类 17/40/42/45/48/49/50，灾害应急类 60/61

## 目录说明

- `learning-roadmap.md` 0 基础学习路线（5 个阶段）
