## 一句话主线（开场直接说）

这五篇论文串成我方向的一条完整链条：灾害信息入口 → 知识表示 → 知识增强×多 Agent → 多 Agent 自动编排 → 灾害落地。它们各自解决一段，但把「知识增强」和「多智能体」合起来做灾害决策研判，目前还是空白——这正是我要做的。

## 第 1 篇：灾害信息入口的鲁棒性评测

**Evaluating Robustness of LLMs on Crisis-Related Microblogs across Events, Information Types, and Linguistic Features**（WWW 2025）

- 解决什么：灾害时推文海量又杂，监督模型换一场灾害就得重新标注训练，来不及；想知道大模型「不训练直接上」行不行。
- 怎么做：6 个大模型（GPT-4o / GPT-4 / GPT-3.5 / Llama-2 / Llama-3 / Mistral）在 19 场真实灾害、7.7 万条推文上做零样本 / 少样本分类，对照监督训练的 RoBERTa。
- 关键结果：闭源强于开源，但都不如监督 RoBERTa（0.78）；三大软肋——洪水最难、求助/急需类最难识别（F1 < 0.60）、错别字拖后腿；给示例（few-shot）基本没用。
- 和我的关系：这是我链条的「入口层」，我复现过，并补了错别字的因果对照实验。它全是英文数据，中文入口是空白。

## 第 2 篇：时空知识图谱

**SSTKG: Simple Spatio-Temporal Knowledge Graph for Interpretable and Versatile Dynamic Information Embedding**（WWW 2024）

- 解决什么：现实知识随时间 + 空间变化，普通知识图谱是静态的，装不下。
- 怎么做：简单时空知识图谱框架，三步嵌入（交互表示 → 轨迹表示 → 时空聚合）把空间和时间融进图，输出用于时间预测和空间推荐。
- 关键结果：在零售销量、交通流量等时空任务上有效；方法简单、解释性强。
- 和我的关系：灾害态势天然是时空的（震中 / 受灾区 / 救援队 / 时间演化），这篇是「把灾害数据装进图」的模板。

## 第 3 篇：知识增强 × 多智能体

**Taming the Untamed: Graph-Based Knowledge Retrieval and Reasoning for MLLMs to Conquer the Unknown**（ICCV 2025）

- 解决什么：多模态大模型在罕见领域知识不足、检索冗余且相关度低。
- 怎么做：以游戏《怪物猎人》为测试床，构建多模态知识图谱 MH-MMKG 和复杂查询，提出无需训练的多智能体检索器，让模型自主在图里搜知识再推理。
- 关键结果：显著提升领域问答与推理表现。
- 和我的关系：这是「多 Agent 去查知识图谱」最贴我方向的机制原型——我灾害场景里的「情报员查知识库」就是这回事。

## 第 4 篇：多智能体自动编排

**MetaAgent: Automatically Constructing Multi-Agent Systems Based on Finite State Machines**（ICML 2025）

- 解决什么：多智能体系统靠人手工设计角色，又累又僵；现有自动设计方法缺工具集成、依赖外部数据、通信结构死板。
- 怎么做：给定任务描述，基于有限状态机自动设计多智能体系统并用优化算法打磨；部署时由状态机控制智能体的动作与状态转移。
- 关键结果：超过其他自动设计方法，接近针对任务人工精调的系统。
- 和我的关系：我灾害场景的「情报 / 研判 / 校验 / 决策」班子，可以靠它自动编排、自动调。

## 第 5 篇：灾害场景落地

**Sim911: Towards Effective and Equitable 9-1-1 Dispatcher Training with an LLM-Enabled Simulation**（AAAI 2025）

- 解决什么：911 接线员培训靠真人陪练，又贵又累，还照顾不到少数群体。
- 怎么做：三个创新——用历史通话数据建场景、上下文感知的受控生成、带循环纠错的验证。
- 关键结果：在纳什维尔应急通信部门真实部署，90% 受训者认为等同或优于真人培训。
- 和我的关系：证明「灾害 + 大模型」可行；但它只做培训，不做「态势推理 + 辅助决策」——这正是我的空白。

## 总结与我的切入点

五篇拼图：入口（09）+ 知识表示（21）+ 知识增强×多 Agent（23）+ 编排（42）+ 落地（63）。共同指向一个空白：**没有人把「知识增强」和「多智能体」合起来，完成一次灾害全链条的态势研判与辅助决策，也没有评测它的基准。**

我的切入点就是建这样一个基准（CrisisBench）：中文灾害场景 + 三层标注（事实 / 推理 / 决策）+ 消融评测（单 Agent vs 多 Agent、有无知识库）。
