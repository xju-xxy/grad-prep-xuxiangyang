# 研究想法 01：面向移动实体的时空知识图谱灾害推演

**要解决的问题（motivation）**

灾情演化里最要命的是"动"：洪水沿河道移动、余震沿断裂带扩散、救援力量在路网
上调进调出。而我读到的时空知识图谱方法（比如 WWW'24 的 SSTKG）清一色假设
**实体位置固定**，只让关系数值随时变。灾害里恰恰相反：位置在变，影响力作用
对象也在变。静态结点假设导致两张图的问题——扩散路径算得滞后，调配决策做得
不准。

**核心思路 / 创新点**

把 STKG 里的"静态结点 + 流动影响力"扩展成"**结点可移动 + 影响力随相对距离
动态重连**"：

1. 结点位置不再给定，而是带速度/意图变量的可迁移结点；
2. 影响力权重不只看距离阈值，再加**障碍与风险场**（路况、地形、次生灾害带）
   的调节因子；
3. 每轮推演可把"知识图谱当前快照"抽成 prompt 给 Agent 查——这一步用 ReAct
   式的 grounding，Agent 的每句研判都必须落到图谱证据上。

**初步实验方案**

- 数据：公开灾情数据集（如 HumAID 推文提取事件）+ 合成扩散仿真（用简单的
  传播模型造带真值的移动实体轨迹）
- 基线：SSTKG、ST-GCN、固定结点版自己方法的消融
- 指标：链路预测 ACC@n（对齐 SSTKG 口径）+ Agent 推演正确率的人工/LLM 评估

**拟投期刊或会议**

WWW / CIKM（时空知识图谱主线）；偏应用的版本可投 Information Systems 或
KBS 一类期刊。
