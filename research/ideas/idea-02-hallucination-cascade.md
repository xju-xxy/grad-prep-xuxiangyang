# 研究想法 02：用知识增强抑制多智能体"幻觉级联"

**要解决的问题（motivation）**

IJCAI'24 那篇多智能体综述点名了一个还没人解的坑：**幻觉级联**。A 智能体
编造一个"事实"，B 引用它、C 再加工，几轮对话之后源头已不可考，最后决策
建议看起来头头是道、其实建立在假的地基上。灾害决策是高代价场景，这比
普通问答里的幻觉严重得多。Sim911 的消融实验又给了我一个实证：把知识库
关掉，生成质量指标立刻血崩——知识增强至少对"单智能体生成"是管用的。
那它对"多智能体级联传播"管不管用？目前没有系统验证。

**核心思路 / 创新点**

给多智能体系统加一个**发言前检索 + 发言后校验**的双闸门：

1. 发言前：每个 Agent 生成内容前强制检索领域知识库/图谱，要求引用条目 ID；
2. 发言后：一个轻量"事实审核 Agent"对每条断言做实体级校验（对齐 LogiDebrief
   里"机器可执行检查"的思路），不合格的断言打回重说；
3. 观测指标不是平均分，而是**级联溯源**：故意在知识库里埋不一致项，看错误
   在多轮对话里的扩散范围与衰减速度。

**初步实验方案**

- 平台：基于 AutoGen 或自己写的编排，4 个灾害研判 Agent（情报/研判/决策/审核）
- 对比：无闸门 / 只发言前检索 / 只发言后校验 / 双闸门
- 度量：每轮断言的实体级事实错误率、错误扩散轮数、最终报告错误率、
  token 成本增量（诚实地算经济账）

**拟投期刊或会议**

EMNLP（Findings 起跳）或 ACL；实验做厚了可考虑冲 ACL 主会。
