# R1/R4/R5 裁定建议（供标注人确认）

> 证据来源：`results/exp-all-multi-20261018-230557.json`（规则+flash 裁判）与其 plus 重打分文件。
> 裁定依据：逐条回查 **被测报告原文** 是否真正满足要点，并核对规则裁判的命中词。

## 一、R1 匹配词泄漏（3 条）

### 1. S012 F8「推算火势蔓延至东片住宅时间（30米÷每分钟2米，约15分钟）」

- 匹配词：`15分钟、约15、一刻钟、15分、十余分钟`
- 情报原文含："县消防救援大队2支与水罐车3辆正在赶来，到场约需15分钟"（**语义完全不同**）
- 被测报告原文含：**"火势蔓延迅速，预计15分钟内将威胁到东片住宅区"** → 报告**确实做出了推算**，本点应判 1
- 三裁判：规则=1 / flash=1 / plus=1 → 多数票=1
- **裁定：改（仅收窄匹配词，属预防性）**。匹配词收窄为 `15分钟内将威胁、约15分钟到达、15分钟内蔓延、一刻钟、15分内`，避免"救援队到场15分钟"被误命中。
- **结果影响：无**（报告仍含"15分钟内将威胁…"，规则仍判 1，多数票不变）。

### 2. S020 F8「推算失联村2天应急口粮量（45户×3人≈135人×0.5公斤×2天≈135公斤）」

- 匹配词：`135公斤、一百多公斤、百来公斤、口粮、135人`
- 被测报告原文：**不含** "135公斤/口粮/一百多/百来"；规则裁判**唯一命中的是"135人"**（情报已给的中间量）
- 三裁判：规则=1 / flash=1 / plus=0 → 多数票=1
- **结论：确凿的规则假阳性**——报告根本没算出口粮量，却因复述"135人"得分
- **裁定：改**——从匹配词中**删除"135人"**（保留 `135公斤、一百多公斤、百来公斤、口粮`）
- **结果影响：有**。修正后规则→0，三票变为 0/1/0 → **多数票 1→0**，multi 在该点少得 1 分，需重算指标。

### 3. S028 R3「结论：推算滞留人员每日最低饮水约需3吨（1500人×2升）」

- 匹配词：`3吨、饮水、补给、增援、需求、1500`
- 被测报告原文：**不含** "3吨/饮水"；规则命中词为 `补给、需求、1500`（其中"补给/需求"为泛词，"1500"是情报已给的输入量）
- 三裁判：规则=1 / flash=1 / plus=0 → 多数票=1
- **结论：确凿的规则假阳性**（泛词 + 泄漏输入量共同致误）
- **裁定：改**——**删除"1500""补给""需求"**（保留 `3吨、饮水、增援`）
- **结果影响：有**。修正后规则→0 → **多数票 1→0**，multi 少得 1 分，需重算指标。

## 二、R4 措辞含糊（16 条）

**结论：15 条保留不改，1 条仅修匹配词。**

- **保留理由**：这些要点含"尽快/做好/确保/合理"等词，但其**判定对象仍是"具体对象＋具体动作"**（如"对已出现刺激症状的人员送医，并通知医院、疾控做好接诊"），限定词只描述时效/态度，不破坏 0/1 客观判定。且**修改要点文本会改变 LLM 裁判的输入**，使已发布的 v0.4 裁判结果失效、必须全量重跑，代价与收益严重不匹配。建议留待 v0.5 统一措辞时一并规范。
- **例外（1 条，仅改匹配词，不动要点文本）**：
  - **S001 D6**「救援力量按村落风险部署（合理使用救援队与卫星电话，不虚构外来力量）」
    匹配词 `分配、部署、救援队、卫星电话、优先、力量` 中 **"优先""力量"为泛词**，易被"优先救援""投入力量"等泛述误命中。
    **裁定：删除泛词"优先""力量"**，保留 `分配、部署、救援队、卫星电话`。
    结果影响：需重算规则口径（对多数票影响待重算确认）。
