# CrisisBench v0.4 成本与延迟（A8）

> 口径：三裁判多数票协议下的实测 API 调用；数据源为结果文件记录的 usage 字段，无估算。
> 「主运行」含被测智能体推演调用与 1 次被测同侧裁判调用；「plus 裁判」为正式口径所需的第二次 LLM 裁判；
