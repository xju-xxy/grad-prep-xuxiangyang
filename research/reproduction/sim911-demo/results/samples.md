# Sim911 复现：生成的呼叫样例

> 模型 glm-4-flash，2026年10月。下面全是真的跑出来的原文，我把模型输出的三个字段照抄下来。
> 每条后面的括号是这一条实际花了几轮（1 = 一次过，3 = 打回三次还是没过）。

## 完整条件（画像 + 知识库都开着）挑几条

**E01 心脏骤停 / P1 非母语者（3 轮，地址真实✅，画像判成 P8 ✗）**

- 地点：江城路130号阳光花园5栋101
- 原话：我……门，开不了。阿姨，倒地，不动。阳光花园，5栋，101。
- 求助要点：阿姨倒地不动，急需急救。

**E05 火灾 / P4 情绪崩溃者（1 轮，全过）**

- 地点：光明街12号幸福小区1栋804
- 原话：哎呀，我…我在幸福小区，3楼着火了，烟…烟太大，我…我…我怎么办啊，我奶奶还在屋里呢，快…快来人啊！
- 求助要点：奶奶还在屋里，情况紧急

**E07 交通事故 / P6 听障人士代拨（2 轮，全过）**

- 地点：建设路45号和平里2单元601
- 原话：您好，我隔壁的出了点事，在建设路和平里这边，我问他一下啊——他说驾驶座有人卡住了，车门也打不开。
- 求助要点：驾驶座有人被卡住，车门打不开。

**E13 一氧化碳中毒 / P2 低收入社区居民（2 轮，全过）**

- 地点：光明街18号幸福小区6栋302
- 原话：哎哟喂，120吗？我们这边出大事了，就在光明街那边的幸福小区，就那个卖早餐的旁边，有人头晕得厉害，快帮忙看看吧！
- 求助要点：有人头晕得厉害，快帮忙看看！

**E20 异物卡喉 / P6 听障人士代拨（1 轮，全过）**

- 地点：光明街12号幸福小区1栋804
- 原话：您好，我是幸福小区的，我问他一下啊——他家里有个老人，吃年糕卡住了，说不出话来，只能指喉咙，我问他一下啊——他家人只会拍背，我问他一下啊——他家人说老人现在好像有点意识不清了。
- 求助要点：老人吃年糕卡住，意识不清，需要急救。

这条是全场最能说明"画像注入有用"的一条：三种"我问他一下啊"硬塞进去，就是转述时来回确认的样子。
但也暴露了毛病——同一句口头禅连说三遍，明显是在搬我给它的风格样例。

**E21 过敏性休克 / P7 儿童代拨（2 轮，全过）**

- 地点：江城路130号阳光花园5栋101
- 原话：妈妈，我姐姐她吃了花生，嘴唇现在好大哦，好像喘不上气了，在阳光花园5栋101，你们快来吧。
- 求助要点：姐姐吃了花生，嘴唇肿，喘不上气。

首轮版本是"喂，阿姨，我妈妈在家里吃了个花生……"，被裁判判成 P2 打回，重生成以后
"阿姨"改成了"妈妈"、"好大哦"这种小孩腔才出来。打回重生成这次是真起了作用。

**E25 中风 / P1 非母语者（3 轮，地址真实✅，画像判成 P8 ✗）**

- 地点：光明街18号幸福小区6栋302
- 原话：我……说话，不好。人，倒下了，不动了。这是幸福小区，六栋三零二。
- 求助要点：家属想喂水，不知道能不能喂

**E29 电梯困人 / P3 独居老人（3 轮，地址真实✅，画像判成 P8 ✗）**

- 地点：江城路128号阳光花园3栋502
- 原话：喂，喂？是我，我……我住在阳光花园，3栋502，电梯里头，我有点儿……有点儿喘不上气了，你们快来吧。
- 求助要点：里面有个老人，他现在胸闷，喘不上气。

**E30 心理危机 / P4 情绪崩溃者（2 轮，全过）**

- 地点：建设路47号和平里4单元203
- 原话：我……我在这儿，建设路，和平里，他……他在这儿，他在这儿，你们……你们快来啊，救救他，救救他！
- 求助要点：求求你们快点儿来，他在4单元203，快！

**E09 跌倒受伤 / P7 儿童代拨（3 轮，收下了但地址没过）**

- 地点：江城路130号阳光花园5栋101
- 原话：喂，阿姨在浴室摔倒了，好疼啊，她在地上爬不动了，小区里，快帮帮她吧。
- 求助要点：阿姨在浴室摔倒了，需要急救。

这条是反面教材。首轮其实是"喂，阿姨，我奶奶在浴室摔倒了，她躺在地上起不来，疼得厉害，
我们小区的地址是江城路130号阳光花园5栋101。"——地址说清楚了，只是裁判把它判成了 P8 打回。
结果重生成两次越写越差，最后连地址都不说了，孩子腔也跑没了。

## 关掉地址表以后，模型开始瞎编地址

消融的 no_kb 条件，20 条首轮 20 条全是编的。挑四条出来看看它编成什么样：

| 事件/画像 | 它编的地点 | 原话（开头） |
|---|---|---|
| E11 燃气泄漏 / P1 | 北京市朝阳区朝阳北路123号 | 啊，这里，这边，煤，气味，很浓，整个楼都有，不敢开灯，不敢开电器，啊，快，快救…… |
| E17 触电 / P4 | 上海市浦东新区东方路1234号 | 哎，我，我这边工地有人触电了，就在，就在东方路那，我，我…我朋友他…他… |
| E07 交通事故 / P6 | 和平大道与解放路交叉口 | 您好，我是XX小区的，我问他一下啊——他说那边十字路口两辆车撞上了，有人被卡在驾驶座上，车门打不开。 |
| E01 心脏骤停 / P1 | XX市XX区XX路XX号 | 我……这里，XX路，XX号，有人，倒地，不动，门，关着。 |

有意思的是它能感觉到自己手里没地址，就退而用「XX市XX区XX路XX号」这种占位符，
甚至直接写了两个真实城市名（北京、上海）现编门牌。这跟论文说的"没有事实库撑腰，
模型会编地址、会悬浮"是一模一样的现象。
