# AutoGen 复现笔记（多智能体应急会议）

> 复现论文：AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation（微软，ICLR 2024 Workshop）
> 使用模型：智谱 GLM-5.3-Flash（API 方式）
> 复现时间：2026年10月

## 这个项目做了什么

复现 AutoGen 论文的核心机制：**多个大模型智能体通过对话协作，共同完成一个任务**。
我把它放到了灾害场景里——模拟一场"县级应急指挥会议"：

- 【信息官】唯一能联网搜索的角色，负责查事实（有工具）
- 【分析师】读会议记录做态势研判（没工具）
- 【顾问】综合研判给行动建议（没工具）

三个角色按"信息官 → 分析师 → 顾问"的顺序开两轮会，每轮都能看到之前的全部发言，
最后顾问输出一份《最终决策建议报告》。主持人角色（我的程序）负责控制流程、替信息官执行搜索。

灾害问题是我方向上最典型的场景：地震发生后指挥部要第一时间做态势研判和响应部署。

## 为什么不用现成的 AutoGen 库

做过功课之后决定手写。原因写在前面，也是我跟导师汇报时要说明的一点：
微软的 AutoGen 库聚焦在 OpenAI 的模型上，用它接国内模型需要配 OpenAI 兼容转发，
对复现"对话协作"这个核心机制来说不是必要的。
论文真正的核心是那套多智能体对话框架：**给每个 Agent 一个角色卡（system prompt），
让它们共享一份对话记录，轮流发言**。这套机制其实几十行代码就能搭出来。
手写还有一个好处：每一行都是自己的，不存在"调了库但讲不清内部怎么工作"的问题。

## 怎么运行

```
# 装依赖（.venv 已有的话跳过）
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

# .env 里填智谱 API Key

# 跑默认的地震应急场景
.venv\Scripts\python.exe multiagent.py

# 换自己的问题
.venv\Scripts\python.exe multiagent.py "你的灾害场景问题"
```

## 文件说明

- `multiagent.py` 主程序：会议循环、工具执行、终稿生成
- `roles.py` 三个角色卡
- `tools.py` 联网搜索工具（信息官专用）
- `requirements.txt` 依赖

## 关键设计（自己的思考）

**1. 角色卡决定行为边界。** 分析师的角色卡里专门写了"不写行动方案，那是顾问的活"，
顾问的卡里写了"不做搜索、不重复信息"。没有这些约束，三个角色很容易输出雷同的内容，
多智能体就没有意义了——分工必须靠提示词硬性划出来。

**2. 工具只给一个角色。** 搜索能力只授予信息官，搜索结果以"系统备注"的形式进会议记录，
其他角色只能读、不能用。这避免三个角色各自乱搜，浪费额度还互相矛盾。

**3. 会议记录是共享记忆。** 每个角色发言前，程序把完整会议记录拼进 prompt。
角色之间的信息传递全靠这份记录，没有别的通道。这跟论文里"对话即信息流"的设计一致。

**踩坑记录：** 信息官第一版实现只让它搜一轮，结果它对有的问题只搜一次就硬编细节。
改成"不满足就继续搜，最多连续 2 次"之后好多了。另外新版 zhipuai sdk 装完会缺 sniffio
这个间接依赖，requirements 里补上了。

## 测试记录

用默认问题（6.8级地震应急研判）跑通：
信息官搜索了真实的地震应急资料 → 分析师基于会议记录给出研判（没有自己编数字）→
顾问输出可落地的优先级清单和 24 小时分工 → 最终报告五段结构完整。
会议记录里能看到角色之间的信息传递链：信息官的原话 → 分析师引用 → 顾问再引用。

## 和原论文的差别

- 原论文支持任意数量 Agent、任意拓扑的对话（群聊模式），我固定成 3 角色 2 轮
- 原论文的停机条件是对话中喊 TERMINATE，我用的是固定轮数，简单但够用
- 原论文支持人类中途介入（human-in-the-loop），我这里没有做
- 没有做原论文的定量评测（HumanEval 等），只做了场景演示

## 和第一篇 ReAct 的关系

第一篇证明"一个智能体能边想边查"，这一篇证明"多个智能体能分工开会"。
两个机制合起来，就是 AutoGen 论文里 assistant + user proxy 的完整形态：
一个会调用工具的干活的 agent + 一个主持对话的 agent。
这也是我"知识增强的多 Agent 灾害态势推理与辅助决策"课题最重要的两个地基。
