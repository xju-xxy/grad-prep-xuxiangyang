# 41 LLM 多智能体综述 论文笔记

**论文**：Large Language Model based Multi-Agents: A Survey of Progress and Challenges
（Taicheng Guo、Xiuying Chen 等，Notre Dame / KAUST / 南科大，IJCAI 2024 Survey Track，arXiv:2402.01680）
**读的时间**：2026年10月

---

## 一句话总结

这是目前我读过对"多智能体系统"拆得最清楚的一篇综述：不管哪个系统，
不外乎回答四个问题——每个 Agent 是什么人设、跟环境怎么交互、彼此怎么说话、
能力怎么长起来。拿这四个抽屉去套任何一篇多智能体论文，都能装进去。

## 核心框架（大白话版）

- **Agent-Environment Interface（和环境的关系）**：分三类。Sandbox 是人造沙盒
  （代码解释器、游戏世界），Physical 是真实物理机器人，None 就是关起门纯讨论。
- **Agent Profiling（人设）**：Pre-defined 是人工写死角色，Model-Generated 让模型
  自己生成角色，Data-Derived 从现有数据集里挑。我现在做的灾害系统里"情报官/
  研判官/决策官"就是第一种。
- **Agent Communication（怎么交流）**：范式上分合作、辩论、竞争三种；结构上有
  分层、去中心化、中心化、共享消息池。MetaGPT 那套"SOP + 消息池"被当成标杆
  反复拿出来讲。
- **Capability Acquisition（怎么变强）**：反馈来源四选一（环境 / 其他 Agent /
  人类 / 没有），调整手段有记忆机制、自我进化、动态生成新 Agent。记忆这一块
  和我关心的"知识增强"是一条线：外部向量库检索本质就是给 Agent 装长期记忆。

典型实例点名了很多：多代理辩论（Du et al. 提升事实性）、ChatEval 互评、
MetaGPT、ChatDev、CAMEL，竞争类的狼人杀、阿瓦隆，具身类 RoCo 双臂协作。
其中 Xiao et al.（2023）模拟小镇水污染危机下虚拟政府的应急响应，是离我课题
最近的前置工作。

## 论文指出的坑

1. 多模态环境几乎空白，现在都是纯文本
2. 幻觉会在多个 Agent 之间像病毒一样**级联传播**——A 编一句，B 引用了，
   C 再加工，谁都不知道源头是假的
3. 群体层面的协同优化没人做，大家都是逐个 Agent 单点调优
4. 编排成本高、评估基准缺——应急/灾害场景更是没有现成 benchmark

## 我的疑问

1. 综述把"辩论"当成提升事实性的手段，但辩论的轮数、判官的立场都会引入新的
   不确定性。灾害决策里"吵赢了"不等于"判对了"，怎么衡量？
2. "幻觉级联"他们点了名没给解法。我在想知识增强（每个 Agent 发言前先查库）
   是不是最直接的抑制剂——查完就没有"无中生有"的空间了。但这只是直觉，
   没看到对比实验。

## 和我方向的挂点

这篇综述帮我立起了课题的坐标系：我的"多 Agent 灾害态势推理"落在 Communication
=混合结构 + Capability Acquisition=外部知识记忆的交叉点上。综述明说"应急场景
没有 benchmark"，这既是困难也是机会——如果能做出一个带标注的灾害多智能体
推理评测集，本身就是贡献。另外它提的"机制模型（灾害演化）+ 决策模型（人行为）
解耦"的架构思路，我打算在设计自己系统时用。
