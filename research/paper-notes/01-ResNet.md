# 论文笔记 01：ResNet

> Deep Residual Learning for Image Recognition
> 作者：Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun
> 年份：2015 | 会议：CVPR
> 链接：https://arxiv.org/abs/1512.03385

---

## 一、一句话概括

通过引入**残差连接（Skip Connection）**，解决了深度神经网络"越深越难训练"的问题，使得训练上百甚至上千层的网络成为可能。

---

## 二、要解决的问题

### 2.1 背景

在 ResNet 之前，大家发现一个反直觉的现象：
- 网络越深，理论上表达能力越强
- 但实际上，**网络加深到一定程度后，训练误差反而变大了**（不是过拟合，而是训练集上的误差都变大）

### 2.2 为什么会这样？

不是因为网络深了就学不动，而是因为**优化太难了**。直接堆叠卷积层，每多一层，梯度反向传播时就多一次矩阵连乘，梯度容易消失或爆炸，导致深层网络很难收敛。

### 2.3 核心洞察

作者提出一个问题：如果我们已经有一个表现不错的浅层网络，现在想在后面加几层，**能不能让新加的层至少不破坏原有性能？**

理想情况下，新加的层只要学会**恒等映射**（输入等于输出），就能保证性能不下降。但让一堆卷积+激活函数去拟合恒等映射，很难。

---

## 三、核心方法：残差学习

### 3.1 残差连接（Skip Connection）

核心思想：不让网络直接学目标映射 `H(x)`，而是学**残差** `F(x) = H(x) - x`，然后：

```
输出 = F(x) + x
```

也就是：
```
        ┌──────────────┐
x ──────┤  卷积层 F(x)  ├───── + ──────→ H(x) = F(x) + x
   │    └──────────────┘       ▲
   └───────────────────────────┘
        (shortcut / skip connection)
```

### 3.2 为什么这样就好训练了？

- 如果恒等映射是最优解，网络只需让 `F(x) = 0`（把权重学成 0），这比让 `F(x)` 去拟合恒等映射容易得多
- 反向传播时，梯度可以通过 `+ x` 那条短路直接传回前面的层，**缓解了梯度消失**

### 3.3 残差块（Residual Block）

一个基本残差块包含：
1. 卷积层
2. Batch Normalization
3. ReLU 激活
4. 卷积层
5. Batch Normalization
6. 加上输入 x（shortcut）
7. 最后再过一个 ReLU

当输入输出维度不同时（比如通道数变了），shortcut 上需要加一个 1×1 卷积来调整维度。

---

## 四、网络结构

ResNet 有多个版本，按层数分：

| 版本 | 层数 | 参数量 |
|------|------|--------|
| ResNet-18 | 18 层 | ~11M |
| ResNet-34 | 34 层 | ~21M |
| ResNet-50 | 50 层 | ~25M |
| ResNet-101 | 101 层 | ~44M |
| ResNet-152 | 152 层 | ~60M |

结构特点：
- 开头：7×7 卷积 + MaxPool
- 中间：4 个 stage，每个 stage 堆叠若干残差块，通道数逐渐加倍，特征图尺寸逐渐减半
- 结尾：全局平均池化 + 全连接层（分类）

---

## 五、实验结果

- 在 ImageNet 图像分类任务上，ResNet-152 取得了当时最好的成绩
- ResNet-50 比 VGG-16/19 准确率更高，参数量却只有 VGG 的一半左右
- 作者还做了 CIFAR-10 上的实验，训练了一个 **1202 层**的网络，依然能正常训练并取得不错的效果（证明了残差连接确实能支撑极深网络）

## 六、我的理解与思考

### 6.1 为什么这篇论文重要？

ResNet 是深度学习历史上**最重要的论文之一**，原因：
1. 它解决了"深度"这个核心瓶颈，让网络可以做得很深
2. 残差连接这个设计极其简单但极其有效，几乎影响了之后所有的网络设计
3. 现在的 Transformer、大语言模型里到处都能看到残差连接的影子

### 6.2 我学到的设计思想

- **让优化变简单，而不是让模型变复杂**：残差连接没有增加多少计算量，但大大降低了优化难度
- **恒等映射是个好东西**：给网络留一条"什么都不做"的退路，比强迫它学新东西更稳健
- **梯度通路很关键**：shortcut 本质上是给梯度开了一条高速通道

### 6.3 可以延伸的方向

- 残差连接在医学影像分割中的应用（U-Net 也有类似的跳跃连接思想）
- 残差连接和 Transformer 的结合（如 ResViT）
- 如何让残差连接更高效（如 1×1 卷积的优化）

## 七、复现计划

- 数据集：CIFAR-10（60000 张 32×32 彩色图片，10 个类别）
- 框架：PyTorch
- 目标：实现 ResNet-18，在 CIFAR-10 上达到 90%+ 准确率
- 步骤：
  1. 搭建 ResNet-18 网络结构
  2. 准备 CIFAR-10 数据加载
  3. 训练（交叉熵损失 + SGD 优化器）
  4. 评估准确率，画 loss 曲线
